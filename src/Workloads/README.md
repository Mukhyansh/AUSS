## Workloads!

***~This is the Workloads section of this project and it contains synthetic processes which are going to be used for telemetry reading!***

*1: "byteReader" is an I/O intensive workload.*

*2: "matrixMultiplication" is a CPU intensive workload.*

*3: "Compressor" is a mixed workloads (intensive on both).*



## Makefile Instructions

**Run these to compile the workloads section!**

`make all` or `make` :

    This will compile every workload and produce the executables!

`make test-all` :

    This will execute the "Activate_Workloads.c" file.

`make help` :
    
    This is for overall help, I have written everything for the help sections!

`make clean` :

    This is for cleaning up the executables after a successful or unsuccessful run.

### ~Refer to the first two points for execution , the rest can be found in the help sections!
